# 环境 / 工具坑

> 层：**项目知识**（长期有效，与谁在做无关）｜总览见仓库根 `AGENTS.md`。
> 按「现象 → 根因 / 对策」一行一条。**踩到怪现象时查这里，不要凭直觉改代码。**
> 分节按「工具域」而不是按项目；**用不到的小节直接删掉，不留空标题。**

## B. 构建 / 依赖 / 文件锁

- 构建缓存 / 依赖版本不一致导致「产物里有、运行时没有」→ 先清缓存并稳定复现，再怀疑代码；版本钉死在锁文件里，别用 `^`。

## C. 终端 / 脚本 / 工具链

- 脚本改文件后出现「内容没变但整文件重写」→ 先确认换行（CRLF / LF）与编码（BOM），再用结构化写法改。

## G. 前端 / 浏览器 / UI

- 组件宿主元素的盒模型由框架控制 → 间距 / 定位写在原生包裹节点上，不要写在组件标签的 class 上。
